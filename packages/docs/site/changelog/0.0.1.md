Initial Rivus monorepo.

- `@rivus/core`, `@rivus/api`, `@rivus/website`, `@rivus/worker`, `@rivus/app`,
  and this documentation site.
- Fastify API on MongoDB Atlas with JWT auth and a generated OpenAPI reference.
- Cloudflare Worker for scheduled and on-demand tasks.
- pnpm + Vitest + Biome + tsdown toolchain with supply-chain hardening.
